# Mancha Urbana
## Objetivo
Crear un modelo de Machine Learning capaz de detectar y predecir el crecimiento de la mancha urbana a través de imágenes satelitales.  

**Importante:** En este repositorio se encuentra una versión muy temprana del proyecto, especialmente los scripts Urbanizacion-3.0.py y main.py  
download_landsat.py tiene el propósito de automatizar la descarga de imágenes satelitales utilizando la API Planetary Computer de Microsoft, así como llevar a cabo un preprocesamiento temprano.  
visualize_rgb.py fue creado para generar imágenes RGB, permitiendo supervisar la integridad de los datos descargados.  
La versión completa del proyecto no puede ser compartida debido a asuntos de confidencialidad académica. No obstante, este repositorio busca permitir un acercamiento a la metodología al trabajar con este tipo de datos.
